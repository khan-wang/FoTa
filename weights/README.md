# Pretrained weights

Checkpoint files are distributed outside the Git repository because each file
is larger than GitHub's normal file-size limit. See [MODEL_ZOO.md](../MODEL_ZOO.md)
for download locations, expected filenames, and SHA256 checksums.

Place downloaded files in this directory, for example:

```text
weights/
  fota_places2_256_seed3407_ema.weights.pth
  fota_celebahq_256_ema.weights.pth
```
