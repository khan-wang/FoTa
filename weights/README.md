# Pretrained weights

See [MODEL_ZOO.md](../MODEL_ZOO.md) for checkpoint download locations,
expected filenames, and SHA256 checksums.

Place downloaded files in this directory, for example:

```text
weights/
  fota_places2_256_seed3407_ema.weights.pth
  fota_places2_512_ema.weights.pth
  fota_celebahq_256_ema.weights.pth
  fota_celebahq_512_ema.weights.pth
  fota_celebahq_1024_ema.weights.pth
```
